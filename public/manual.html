主催者マニュアル

講習の中身をAIで復習用の教材にして、参加者がスマホで見返せるようにするアプリです。次の回まで、学ぶ熱を冷まさないための仕組みが入っています。

1このアプリでできること

講習いつもどおり行い、録画かメモを残す
Claude録画の文字起こしから、復習用の中身を作る
アプリ貼って直して、公開する
便り当日夜・3日後・7日後・次回前に送る
参加者スマホで見返し、足あとを残す

参加者の画面

  • 黒板：次の回まであと何日か、次回までのお題、次の回の準備（3つ）
  • 回のページ：今日の3つ（要点）、録画、1分のおさらい音声（講師の声）、テキスト、用語集、確認問題、やってみた
  • 足あと：やったことが一つ増えるたびに、黒板に「正」の字が一画ずつ書き足されます
  • 質問：名前なしで講師に届き、講師の答えが全員に見えます

講師の画面

  • 中身：回を足す・直す。Claudeへの頼み文をコピーして、返ってきた文を貼るだけで回のページができます
  • 便り：参加者に送る文面をアプリが作ります。コピーしてLINEやメールで送ります
  • 様子：何人がやってみたか、準備がととのったか、しばらく動きのない人が何人か
  • 質問：届いた質問に答える
  • 設定：講座の名前、講師のひとこと、使わない言葉など

アプリはあなた自身のCloudflare（クラウドフレア）のアカウントに、ボタンひとつで置きます。参加者の記録は、あなたのアカウントの中だけに残ります。

2用意するもの

もの何に使うか
Cloudflare のアカウントアプリの置き場所。dash.cloudflare.com で作れます
GitHub のアカウント置くときに、アプリの控えがここに作られます。github.com で作れます
Claude などのAI講習の文字起こしから、復習用の中身を作る
YouTube のアカウント録画を載せるとき（限定公開で載せます）
参加者への連絡手段LINE、メールなど。便りを送るとき

置くときだけ、パソコンがあると楽です。置いたあとは、スマホだけで使えます。

料金や無料で使える範囲は、各サービスの公式の案内で確かめてください。画面の名前やボタンの位置も変わることがあります。このマニュアルと違っていたら、公式の案内が正しいです。

3置く（はじめの一回）

ボタンを押して、画面の案内に沿って進むだけです。文字を打つ窓（ターミナル）は使いません。10分ほど見ておいてください。

  1. ボタンを押す
    Deploy to Cloudflare（ここを押す）
    開かないときは、このアドレスを開きます：
    https://deploy.workers.cloudflare.com/?url=https://github.com/yukawa-care/tsugi-no-kai
  2. Cloudflare と GitHub に入る
    Cloudflare に入り、GitHub とつなぐよう言われたら、案内のとおりに許可します。
  3. 名前を確かめる
    アプリの名前が出ています。そのままでかまいません。講座を二つ以上置くときや、名前を変えたいときは、英小文字・数字・ハイフンで付け直します（例：ai-seminar）。アドレスの一部になります。データベースなどの欄も、出てくるものはそのままでかまいません。
  4. 置くボタンを押す
    いちばん下の「作成してデプロイ」にあたるボタンを押します。数分待つと、アドレス（https://〜.workers.dev）が出ます。
  5. すぐにアドレスを開く
    「はじめの設定」が出ます。次の章へ進みます。

アドレスに自分の名前を出したくないとき

アドレスの 〜.workers.dev の前の部分（サブドメイン）は、Cloudflareのアカウントを作ったときに、メールアドレスの名前などから自動で付きます。参加者に見せたくない名前が入っていたら、Cloudflareの「Workers & Pages」の画面で、サブドメインを変えられます（例：ai-seminar.manabi.workers.dev）。変えると、そのアカウントで置いたアプリすべてのアドレスが変わるので、参加者にリンクを送る前に変えておきます。自分のドメイン（例：kouza.example.jp）を持っていれば、それをつなぐこともできます。

置いたら、すぐ開いてください　最初に「はじめの設定」を済ませた人が講師になります。アドレスを人に教えるのは、設定のあとにします。
途中で止まったり、赤い文字が出たりしたら、画面の表示をコピーしてClaudeに貼り、「次の回までを置こうとしたらこうなった」と聞いてください。

講座を二つ以上置くとき

講座ごとに、もう一度ボタンから置きます。名前だけ変えます。

GitHub を使いたくないとき（パソコンの窓から置く方法）

Node.js（nodejs.org の「LTS」）を入れ、一式の zip を開いたフォルダで窓を開いて、次の一行を打ちます。

node oku.mjs

Mac：「アプリケーション」→「ユーティリティ」→「ターミナル」を開き、cd （cd と空白一つ）と打ってからフォルダを窓に引っぱって入れ、Enter。
Windows：フォルダを開き、上の住所の欄に powershell と打って Enter。

名前を聞かれたら答え、ブラウザが開いたら Cloudflare で許可します。最後に出たアドレスを、すぐに開きます。

4はじめの設定

アドレスを開くと出てきます。答えるのは4つだけです。

  1. 講座の名前　例：はじめてのAI講座
  2. 講師の呼び名　参加者に出るひとことの「〇〇より」になります
  3. どんな分野か　施術・健康／美容・サロン／経営・商い／趣味・習いごと／そのほか。分野に合わせて、Claudeへの頼み方と、気をつける言葉の初めの形が入ります
  4. 講師の合言葉　自分で決めます（6字以上）。紙などに控えてください。画面には二度と出ません

「はじめる」を押すと、参加者に送るリンクが出ます。このリンクを送れば、参加者は合言葉を打たずに入れます。リンクは、あとからでも「設定」の画面でいつでも見られます。

これで準備は終わりです。「設定」の画面にはほかの項目もありますが、変えなくても使えます。

回を足しておく

「中身」→「回を足す」で、第1回の題と日時を入れて保存します。中身はまだ空でかまいません。参加者の黒板に「次の回まで あと〇日」が出るようになります。

5講習ごとの流れ

  1. 講習を録画する
    オンラインなら会議アプリの録画、会場ならスマホの録画や録音で。録れないときは、話したことのメモでもかまいません。
  2. 文字起こしを用意する
    録画の文字起こし（会議アプリやAIの書き起こし機能など）か、メモを用意します。
  3. Claudeで中身を作る
    アプリの「中身」でその回を開き、「頼み文をコピー」を押します。Claudeに貼り、いちばん下の「（ここに貼る）」の所に文字起こしを入れて送ります。
  4. 貼って読み込む
    Claudeの返事をそのままコピーし、アプリの「Claudeの返事を貼る」の欄に貼って「読み込む」を押します。形がおかしいとき、使わない言葉が入っているとき、「講師確認」が残っているときは、アプリが知らせます。
  5. 自分で読んで直す
    AIの下書きには、話していないことや言い過ぎが混ざることがあります。必ず自分で読んでから公開します。
  6. 録画と音声を付ける
    録画はYouTubeに「限定公開」で上げ、アドレスを貼ります。「1分のおさらい」は、スマホのボイスメモなどで自分の声で録って付けます（8MBまで）。
  7. 公開する
    「参加者に公開する」に印をつけて保存します。講習の日時を過ぎると、参加者の画面で開けるようになります。
  8. 便りを送る
    「便り」を開くと、送る文面ができています。コピーして、LINEやメールで送ります。予約送信ができる手段なら、まとめて予約しておくと楽です。

便りを送る日

いつ中身ねらい
講習の当日夜今日の3つと、見返す場所覚えているうちに一度見返す
3日後確認問題を1問忘れかけた頃に思い出す
7日後もう1問と「やってみた？」、お題試す後押し
次回の3日前次回の予告とお題次も行こうと思える
動きの少ない週講師のひとこと（全員あて）責めずに戻るきっかけ

次回の冒頭では、届いた質問に答える時間を少しとると、「送った質問が拾われた」という手応えになります。

6参加者に案内する

「便り」の画面のいちばん上に、はじめて案内するときの文面があります。コピーして、LINEやメールで送るだけです。参加用のリンクが入っています。

参加者はリンクを開き、呼び名と数字4けたの番号を決めて入ります。使い方は、巻末の参加者向けの案内を印刷するか、画像にして送ってください。

参加用のリンクは、参加者にだけ送ります。SNSなど誰でも見られる所には載せません。広まってしまったときは、「設定」→「合言葉と暗証番号」→「参加者の合言葉を作り直す」で古いリンクを使えなくできます（もう入っている人はそのまま使えます）。

7様子と質問を見る

様子

参加者の数、この1週間でやってみたを残した人数、次の回の準備がととのった人数、7日以上動きのない人数が出ます。名前つきで出るのは、本人が「講師に見せる」を選んだ人だけです。

動きのない人が多い週は、便りの「動きの少ない週に」の文を全員あてに送ります。名指しで催促はしません。

質問

質問は名前なしで届きます。答えを書いて「答える」を押すと、参加者全員の質問の画面に出ます。当日に話すつもりの質問は「答えずに閉じる」で片づけられます。

参加者が番号を忘れたとき

「設定」→「暗証番号の再設定」でその人の呼び名を選びます。その人は次に入るとき、新しい番号を決めます。

8守ってほしいこと

録画に映る人　参加者の顔・声・名前が映る録画を載せる前に、同意をとってください。映りたくない人がいるときの扱いも、先に決めておきます。
限定公開　YouTubeの限定公開は、アドレスを知っていれば誰でも見られます。外に出たら困る内容は載せません。
個人がわかること　お客さま・患者さんなど、講習の外の人の名前、体のこと、写真を、テキスト・録画・質問・やってみたに残しません。入力欄にも注意書きを出していますが、書かれてしまったら講師側で閉じてください。
講習の中身の権利　ほかの講師の講義や教材を載せるときは、その人の了承を先にとります。
AIの下書き　AIは、話していないことや言い過ぎを書くことがあります。必ず自分で読んでから公開します。
医療・健康・お金などの分野　広告や表現に決まりがある分野では、テキストや便りの言い回しにも気をつけてください。判断に迷うときは、所管の役所や専門家に確認してください。
参加者の記録　参加者の足あと・やってみた・質問は、あなたのCloudflareのアカウントに残ります。何を残し、何に使うかを参加者に伝えてください。

9困ったとき

こんなときこうします
置く途中で止まった・赤い文字が出た画面の表示をコピーしてClaudeに貼り、どうすればよいか聞きます
講師の合言葉を変えたい「設定」→「合言葉と暗証番号」→「講師の合言葉を変える」
講師の合言葉を忘れて、どの端末からも入れないCloudflareの管理画面で、このアプリのデータベース（D1）を開き、コンソールに DELETE FROM settings WHERE k = 'teacher_hash'; と入れて実行します。すぐにアドレスを開くと「はじめの設定」が出るので、合言葉を決め直します。回の中身や参加者の記録は残ります。参加用のリンクは新しくなります
アドレスに自分のメールの名前が入っている第3章「アドレスに自分の名前を出したくないとき」のとおり、サブドメインを変えます。変えたら、参加用リンクを送り直します
参加者が番号を忘れた「設定」→「合言葉と暗証番号」で呼び名を選んで再設定
参加者が「その呼び名はもう使われている」と言われたほかの人と同じ呼び名です。別の呼び名にしてもらいます
回が参加者に見えない「参加者に公開する」に印があるか、講習の日時を過ぎているかを確かめます
録画が出ないYouTubeのアドレスを貼っているか、公開の設定が「限定公開」か「公開」になっているかを確かめます
音声が付けられない8MBより大きいと付けられません。1分ほどに短くします
中身を貼ったら「形が読めない」と出たClaudeの返事の { から } までが欠けずに貼れているか確かめます。だめなら、Claudeに「JSONだけをもう一度」と頼みます

10新しい版にする

ボタンで置いた人

  1. 新しい一式の zip を開きます。
  2. GitHub で、置いたときに作られた自分のリポジトリを開きます。
  3. 「Add file」→「Upload files」で、zip の中の public と src のフォルダを引っぱって入れ、「Commit changes」を押します。wrangler.toml は上げ直しません（あなたのアプリの置き場所の情報が入っているため）。
  4. 数分で、新しい版に置き直されます。記録と合言葉はそのままです。

パソコンの窓から置いた人

新しい zip を開き、前のフォルダの settei.json を写してから node oku.mjs。settei.json がなければ node oku.mjs アプリの名前。記録と合言葉はそのままです。

付録参加者向けの案内

このまま印刷するか、画像にして参加者に送ってください。

次の回まで　つかいかた

講習のあとの、おさらいの場所です。スマホで見られます。

  1. はじめて入る
    講師から届いたリンクを開き、呼び名と、数字4けたの番号を決めます。番号は控えておいてください。別のスマホでも、同じ呼び名と番号で入れます。
  2. ホーム画面に置く
    iPhone：Safariの共有ボタン →「ホーム画面に追加」
    Android：Chromeのメニュー →「ホーム画面に追加」
  3. 講習のあとに見返す
    「一覧」から回を開くと、今日の3つ・録画・おさらい音声・テキスト・問題があります。
  4. 試したら一言
    習ったことを試したら、回のページの「やってみた」に一言残します。
  5. 疑問は質問へ
    「質問」から送ると、名前なしで講師に届きます。

足あと　見返す・問題に正解する・やってみたを残す、などをするたびに、黒板に「正」の字が一画ずつ書き足されます。毎日でなくて大丈夫。週に一つでも十分です。

お客さま・患者さんなど、個人がわかることは書かないでください。
